# YouTube Clone (SuperSimpleDev practice)

A YouTube homepage clone built while following **SuperSimpleDev's HTML & CSS course**. Front-end practice: the header, sidebar and video grid are laid out with flexbox and CSS grid, no framework.

Also includes earlier course exercises: `flexbox.html`, `grid.html`, `position.html` and the `intro-to-html/` folder.

Live: **https://itslucas02.github.io/supersimple-website-az/**

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python -m http.server
```

## Structure

```
index.html        YouTube homepage clone
styles/           general / header / sidebar / video CSS
thumbnails/       video thumbnail images
channel-pictures/ channel avatars
icons/            SVG icons
intro-to-html/    early course exercises
```
